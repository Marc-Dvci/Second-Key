# Evaluation: scam scripts on public cases

Generated by `npm run evaluate` from `cases/cases.json`. Do not edit by hand.

The case set has 22 scam cases, each paraphrased from a public warning page (anz.com.au, consumer.ftc.gov, cybermalveillance.gouv.fr, fbi.gov, ic3.gov, investor.gov, takefive-stopfraud.org.uk), and 10 ordinary payments to a new payee. For every case, the answers a person would give at the moment of paying (payee type and the four yes/no questions) were filled in from the narrative by a separate pass that did not see the script table. The script table was committed (`Add scam script table`) before the cases were added to the repository.

## Results

| Measure | Result |
|---|---|
| Scam cases where the main script names the right family | **21 of 22** |
| Scam cases with at least one script raised | 21 of 22 |
| Ordinary payments with no script raised | 8 of 10 |

Every request to someone new goes to the second key whatever the scripts say. A script briefs the call; it never approves or blocks a payment.
